## 📋 Описание проекта

**Kanban Dashboard** — интерактивная доска для управления задачами с возможностью перетаскивания (Drag & Drop). Создана как тестовое задание.

### ✨ Функционал:

- ✅ **Три колонки по умолчанию** (To Do, In Progress, Done)
- ✅ **Добавление и удаление колонок** с выбором цвета
- ✅ **Добавление, редактирование и удаление карточек** задач
- ✅ **Приоритеты задач** (Low, Medium, High)
- ✅ **Drag & Drop** — перемещение между колонками и внутри колонки
- ✅ **Сохранение данных** в localStorage
- ✅ **Адаптивный дизайн** (десктоп, планшет, мобильные до 390px)
- ✅ **Модальные окна** для создания/редактирования
- ✅ **Обработка ошибок** через Error Boundary
